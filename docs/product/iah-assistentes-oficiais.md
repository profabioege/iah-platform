# Assistentes Oficiais do IAH Educacional

Documento de produto — registra o nome oficial de cada assistente de IA da plataforma e o padrão visual/textual para escrevê-lo. Não é uma especificação técnica: não define schema, tela, rota ou banco. Nenhum código, tela, banco de dados ou migration foi alterado para produzir este documento.

Identificadores internos (arquivos, pastas, componentes, funções, classes, imports, rotas, parâmetros de URL, variáveis de ambiente, tabelas, migrations) não são alcançados por este documento — continuam usando o padrão técnico já em uso (ex.: `mentor-iah`, `docente-iah`), independentemente do nome exibido em texto/interface.

## 1. Padrão oficial dos assistentes

1. **MentorIAH**
2. **DocentIAH**
3. **MaestrIAH**

## 2. Definições

**MentorIAH** é o cowork pedagógico socrático do estudante, contextualizado à missão e disponibilizado somente quando acionado.

**DocentIAH** é o cowork pedagógico conversacional do professor, para planejamento e produção de materiais de aula (arquitetura e interface em `docs/PRODUCT.md`; especificações do Planejador Conversacional em `docs/`).

**MaestrIAH** — nome oficial reservado neste padrão de nomenclatura. Nenhum documento de produto define seu propósito, escopo ou comportamento ainda; este registro não deve ser lido como anúncio de funcionalidade nem como especificação.

## 3. Padrão visual e textual

- Escrever sempre "MentorIAH", "DocentIAH", "MaestrIAH" — sem espaço entre o nome e "IAH".
- Manter "IAH" sempre em letras maiúsculas.
- Não usar variações como "Mentor Iah", "Mentor-IAH" (hífen) em textos de interface.
- Não usar apenas "Mentor", "Docent" ou "Maestr" quando o nome oficial completo for necessário (primeira menção, títulos, rótulos de interface, documentação de produto).
- Referências subsequentes dentro de um mesmo parágrafo/fluxo de texto (ex.: "o Mentor pergunta...", depois de já ter sido nomeado "MentorIAH") não são o nome próprio do produto sendo reintroduzido — permanecem como estão; este padrão rege a introdução do nome, não cada pronome subsequente.

## 4. O que este padrão não altera

- O sentido de regras pedagógicas, fluxos, permissões, salvaguardas ou critérios já documentados em `mentor-iah-constituicao-pedagogica.md`, `mentor-iah-autoria-integridade.md`, `mentor-iah-fluxo-pedagogico-mvp.md` e `mentor-iah-persistencia-sintese-mvp.md`.
- Expressões genéricas que não são o nome próprio do produto — "mentor pedagógico", "papel de mentor", "processo de mentoria" continuam com esse sentido comum quando não se referem ao assistente oficial.
- Nenhum identificador interno (ver acima).
